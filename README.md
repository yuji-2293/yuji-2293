# 名前: 井上　裕司

## 経歴

食品製造工場勤務。部署リーダー職を勤めながら、Webエンジニア転職を目指して、
個人開発・学習を継続しています。

現職では、人員調整、部署間連携による工場の改善活動に取り組み、
基幹システムの活用を通して、仕組みによる課題解決の面白さを実感。
属人化の解消や業務の改善に積極的に取り組んでいます。

現場の課題を整理し、仕組みによる改善をキャリアとしてやりがいにすることに決め、
システムを作り、提供する側に回るべく、エンジニアを目指しています。

RUNTEQの卒業制作としてRailsアプリを開発した後、
そこで発見した設計上の課題を改善するため、
React + TypeScript + Rails API構成へのリプレイス開発を行いました。

### 略歴

- 🍱 新卒で入社した会社の食品製造工場で10年以上勤務
- 👥 現在は製造部門リーダーとしてチーム運営・業務改善を担当
- 💻 RUNTEQ卒業後、Webアプリ開発を継続
- 🔄 Rails + Turboで開発したアプリを React + Rails API構成へリプレイス
- 📝 技術記事を継続的に執筆
